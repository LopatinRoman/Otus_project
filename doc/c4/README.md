# C4 diagrams (Context + Container)

В этом каталоге лежат C4-диаграммы проекта **HR Onboarding Hub (1С)** для MVP.

## Что здесь есть

### 1) Context (уровень контекста)
Показывает участников и взаимодействие на уровне систем:
- HR-специалист
- HR Onboarding Hub (1С, БСП)
- RabbitMQ (очереди команд/ответов)
- ИТ-исполнитель (1С: Управление задачами)

Файлы:
- Исходник: `C4_Context.puml`
- Рендер: `C4_Context.png`

### 2) Container (уровень контейнеров)
Показывает крупные “части” решения и обмен между ними:
- HR Onboarding Hub (1С) как основной контейнер бизнес-логики
- RabbitMQ как брокер сообщений
- ИТ-исполнитель (1С: Управление задачами) как контейнер исполнения ИТ-действий

Файлы:
- Исходник: `C4_Container.puml`
- Рендер: `C4_Container.png`

## Принцип хранения (почему два файла)
C4 предполагает отдельные представления для разных уровней детализации:
- Context — для понимания “кто с кем общается”
- Container — для понимания “из чего состоит решение на крупном уровне”

Поэтому в репозитории лежат **две диаграммы**:
- исходники (`.puml`) — для воспроизводимости и изменений
- PNG (`.png`) — чтобы проверяющий мог открыть где угодно без PlantUML
